### M1 manual acceptance checklist (browser)
1. Open a project in Workshop. Confirm **Upload Images** and **Import ZIP** are both visible and equal prominence (desktop + iPad).
2. Upload one PNG → staging shows it with thumbnail and dimensions → Import → it appears in the asset grid after reload.
3. Select 100 mixed PNG/JPEG/WebP files in one picker action → progress shown, no freeze; bad file shows an error but the batch continues.
4. Drag images anywhere onto the Workshop page; paste an image from the clipboard.
5. Import a corrupt ZIP → error message, no crash.
6. Import a ZIP with `fronts/` + single `backs/` image → shared-back note appears.
7. Repeat imports in any order; duplicates flagged, not lost, not duplicated as blobs.
8. After import choose Keep in Library / Create draft deck / Add to existing deck; cancel leaves no orphaned decks.
9. Reload the browser — all assets, thumbnails, and deck counts intact.

### M2 manual acceptance checklist (browser)
1. Create 3 decks with 60+ total cards via Import → "Create draft deck", then Cards → select → "Add selected cards to deck".
2. Edit a card: rotate 90°, switch contain/cover, zoom/pan, change size preset → preview updates live; reload page → transforms intact.
3. Deck detail: adjust quantities (−/+), reorder entries ↑/↓, remove an entry, set default back; counts update.
4. Duplicate a deck → copy with fresh entry IDs referencing the same images (no blob duplication).
5. Delete a card definition → confirm it disappears from every deck but remains in the asset library.

### M3 manual acceptance checklist (browser)

2. Draw 1, double-tap to flip, drag a card onto another stack (merges, order preserved), shuffle, draw 3 (deals a grid), gather, peek top.

### M4 manual acceptance checklist (browser)

## Guided workflow tour (rewritten)

- The modal feature tour is replaced by a **step-by-step walkthrough rail** docked in the bottom-left. The actual app section stays live and interactive while the rail guides you:
  1. **Library** — create a project (or load the demo, or play the built-in standard 52-card deck)
  2. **Workshop › Import** — upload images/ZIP, Select all valid, Import, create cards
  3. **Workshop › Cards** — flip tiles, select cards, Choose a back for selected cards, rotate
  4. **Workshop › Decks** — create deck, add selected cards, set quantities, pick an icon, Choose a back, Play on Table
  5. **Table** — drag to draw, hold to grab, double-tap to flip, shuffle/cut/deal, snap to the soft grid, Sound/Snap toggles, zoom/pan, undo
  6. **Library** — Export/Import a `.dealwithit.zip` to share
- Each step navigates to the corresponding section (Workshop tabs are now encoded in the hash, e.g. `#/workshop/<id>/cards`). If no project exists, the tour creates the demo deck so every step has real content to interact with.
- Re-open anytime with the **Tour** button in the Library.

## Project deletion & demo dedupe

- Each Library project card now has a **Delete** button (with confirm) that removes the project plus all its images, blobs, cards, decks, tables and thumbnails from IndexedDB.
- "Start with demo deck" no longer piles up duplicates: if a "Demo Deck" project already exists it reuses it instead of creating another.

## Quickstart, handoffs, library deck management

- **Quick start guide**: first-time visitors (no projects yet) see a 3-step panel on the Library — Create a project → Import card images → Build decks & play — with buttons that jump straight to the right place.
- **Step handoffs**: every area ends with a dashed "next step" banner ushering you onward — Library → Workshop, Import → Cards, Cards → Decks, Decks → Table.
- **Demo deck fixed**: the demo now actually fills its deck (18 cards: 6 generated suits × 3 copies). The old code called the immutable `addEntryToDeck` without reassigning the result and referenced asset ids instead of card ids, producing an empty deck.
- **Library deck management**: each project card now lists its decks with inline rename (edit + blur/enter to save), icon picker, Duplicate and Delete buttons.
- **Deck icons**: 24 free icons from the Fractal Symbols library (Felix Thalin, CC BY 4.0 — the same set TokenMaker uses) copied to `public/deck-icons/`, normalized to `fill: currentColor` so they adapt to light/dark themes. Icons show on Library deck rows, Workshop deck gallery tiles, and can be set from both places. Attribution note appears in the quick start panel.

## Visual Workshop redesign

- **Cards tab**: visual card tiles rendered from the actual card definitions (correct aspect ratio, transform applied). Click a card face to flip front ↔ back. Each tile has a per-card **back picker** (assign any imported image as the back, or the neutral generated back), plus Edit / Duplicate / Delete buttons and a "N in decks" counter. Bulk toolbar: rotate selected 90°, apply a back to all selected cards (or remove backs).
- **Decks tab**: graphical deck gallery — every deck shown as a mini fanned stack of its card thumbnails with counts. Create, select, rename (prompt), duplicate and delete decks. The deck editor lists entries with thumbnails, quantity steppers, reorder, remove, and a **Move to → another deck** transfer control (merges quantities if the target already has that card). "Play on Table" button goes straight to the felt.
- **Workflow clarity**: numbered tabs (1 · Import → 2 · Cards → 3 · Decks) and empty-state guidance pointing to the next step.
- New pure operations with tests: `transferEntry` (deck → deck move with quantity merge) and `duplicateCardDefinition`.
